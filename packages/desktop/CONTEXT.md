# Desktop — glossary

The vocabulary `packages/desktop` owns. This is a glossary and nothing else: it says
what a term means and what it is not, never how it is implemented or what the product
should do.

Use these words as written. If a concept you need is not here, either you are inventing
language the project does not use, or there is a real gap worth adding.

**Start folder** — the folder every file dialog opens at when one is set. Not the "home
directory": the operating-system home is already what the file picker falls back to on
its own, and the two must stay distinguishable in prose. German: **Startordner**.

**Content frame** — the centred, width-limited box a screen's content sits in. Not the
mask, which sits inside it. Not the window, which the frame sits inside in turn. German:
**Inhaltsrahmen**.

**Zoom level** — the factor by which the program's text is scaled. Distinct from the
window size and from the operating system's own display scaling; changing one does not
change the others. German: **Zoomstufe**.

**Recent decks** — the short ordered list of decks the learner has opened, newest first.
Distinct from *last deck*, the single most recent entry it supersedes. German:
**Zuletzt verwendete Lern-Dateien**.
