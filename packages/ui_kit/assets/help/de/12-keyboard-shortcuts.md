# Tastaturbefehle

Learn Anywhere lässt sich vollständig über die Tastatur bedienen. Dieses Kapitel ist
die vollständige Referenz; jeder Befehl wird außerdem in seinem eigenen Kapitel im
Zusammenhang erklärt.

## Überall

| Taste | Aktion |
|---|---|
| `F1` | Öffnet dieses Benutzerhandbuch als Dialog über dem, was Sie gerade tun. Funktioniert auf jedem Bildschirm, auch mitten in einer Sitzung oder Bearbeitung — die einzigen Ausnahmen sind ein geöffnetes Menü oder ein bereits geöffneter anderer Dialog |
| `Esc` | Kehrt auf jedem Bildschirm ohne eigene `Esc`-Behandlung (Statistik, Lexikon, Programminfo, Optionen, Mask Editor) zum Arbeitsbereich zurück |
| `Strg` und `+` | Eine Zoomstufe hinauf |
| `Strg` und `-` | Eine Zoomstufe hinunter |
| `Strg+0` | Zurück auf 100 % |

Die drei Zoomtasten sind die einzigen `Strg`-Tastenkürzel im Programm — alles andere ist
eine Funktionstaste oder ein `Alt`-Tastenkürzel. Sie springen zwischen den sechs
angebotenen Stufen, statt stufenlos zu vergrößern; siehe
[Einstellungen](11-settings.md#zoomstufe).

## Menüleiste

`Alt+<Buchstabe>` öffnet ein Menü der obersten Ebene; der unterstrichene Buchstabe in
jedem Namen ist der wirksame. **Statistik** und **Lexikon** sind direkte Aktionen statt
Untermenüs — ihr Tastenkürzel öffnet den jeweiligen Bildschirm sofort.

| Menü | Tastenkürzel |
|---|---|
| Datei | `Alt+D` |
| Edit | `Alt+E` |
| Lern | `Alt+L` |
| Statistik | `Alt+S` |
| Lexikon | `Alt+X` |
| Optionen | `Alt+O` |
| Hilfe | `Alt+H` |

Ist ein Menü geöffnet, hat jeder Eintrag darin seinen eigenen unterstrichenen
Buchstaben, eindeutig innerhalb dieses Menüs (aber nicht zwangsläufig über Menüs hinweg
— derselbe Buchstabe kann in verschiedenen Menüs Verschiedenes bedeuten). Ein Wechsel
bei **Optionen ▸ Sprache** ändert jeden dieser Buchstaben auf sein englisches
Gegenstück; siehe [Einstellungen](11-settings.md#darstellung-und-sprache).

## Lerneinheiten-Editor

| Taste | Aktion |
|---|---|
| `F2` | Vorherige Einheit |
| `F3` | Nächste Einheit |
| `F5` | Suche |
| `F6` | Zu Einheit springen |
| `F7` | Einheit löschen (mit Bestätigung) |
| `F8` | Einheit vor der aktuellen einfügen |
| `F10` | Fertig — Änderungen behalten |
| `Esc` | Abbruch — bei Änderungen mit Rückfrage |
| `Enter` / `Tab` | Nächstes Feld |
| `Rücktaste` (bei leerem Feld) | Vorheriges Feld |

Was jede dieser Tasten im Einzelnen bewirkt, steht in
[Lerneinheiten bearbeiten](04-unit-editor.md).

## Lernsitzung

| Taste | Aktion |
|---|---|
| `F3` oder `Enter` | Antwort prüfen / Weiter |
| `F5` | Bewertungsschaltfläche 1 |
| `F6` | Bewertungsschaltfläche 2 |
| `F7` | Bewertungsschaltfläche 3 |
| `F9` | Antwortansicht durchschalten: Korrektur → Lösung → Ihre Antwort |
| `F10` | Anzeigen (beim Stufenlernen auf Stufe 3: Verdecken & tippen, vor dem Anzeigen) |
| `Esc` | Sitzung abbrechen, zurück zur Einrichtung |
| `Enter` / `Tab` | Nächste Lücke in einem mehrteiligen Feld |
| `Rücktaste` (bei leerer Lücke) | Vorherige Lücke |
| `Pfeiltaste nach unten` | Nächstes Antwortfeld |
| `Pfeiltaste nach oben` | Vorheriges Antwortfeld |

Was jede Bewertungsschaltfläche in einer gegebenen Situation bedeutet, steht in
[Lernsitzungen](06-learning-sessions.md), [Stufenlernen](07-level-learning.md) und
[Wie Antworten bewertet werden](08-answer-evaluation.md#den-versuch-bewerten).

## Optionen und Mask Editor

`Enter` aktiviert die Schließen-/OK-Schaltfläche des Bildschirms, genau wie ein Klick
darauf. `Esc` (global, oben) bricht ab.
