# Learn Anywhere Benutzerhandbuch

Learn Anywhere übt alles ab, was sich als Satz zusammengehöriger Fakten aufschreiben
lässt — Vokabeln, Formeln, Jahreszahlen, chemische Symbole, Gesetzesparagraphen,
anatomische Begriffe. Das Programm selbst weiß über kein Fachgebiet etwas. **Sie**
beschreiben, wie eine Karte aussieht, und Learn Anywhere übernimmt das Abfragen, das
Bewerten und die Buchführung.

Dieses Handbuch ist im Programm enthalten und daher jederzeit offline verfügbar unter
**Hilfe ▸ Benutzerhandbuch** oder mit der Taste `F1`. Es öffnet sich *über* dem, was Sie
gerade tun — auch über einer laufenden Übungssitzung oder einer ungespeicherten
Bearbeitung — und `Esc` bringt Sie genau dorthin zurück.

## Womit anfangen

Wenn Sie Learn Anywhere noch nie benutzt haben, lesen Sie
[Erste Schritte](01-getting-started.md) und danach [Grundbegriffe](02-concepts.md).
Zusammen erklären sie die beiden Ideen, auf denen alles Weitere aufbaut: eine **Maske**
beschreibt die Form Ihrer Karten, eine **Lern-Datei** enthält die Karten selbst.

Wenn Sie vom ursprünglichen *Lern PC plus* kommen: die Begriffe haben sich geändert,
die Ideen nicht. Eine Maske ist weiterhin das Formular, das Sie ausfüllen, eine
Lern-Datei weiterhin Ihre Sammlung von Lerneinheiten, und der Drill läuft weiterhin so
lange, bis alles beherrscht ist.

## Zur Schreibweise in diesem Handbuch

- Menüwege sehen so aus: **Datei ▸ Lerneinheiten laden...**, und zwar genau so
  geschrieben, wie das Programm sie schreibt. Ein Wechsel der Programmsprache ändert
  diese Bezeichnungen; das Handbuch wird mit ihnen zusammen übersetzt, das englische
  Handbuch nennt also die englischen Bezeichnungen.
- Tasten sehen so aus: `F3`, `Esc`, `Strg`, `Alt+H`.
- Dateinamen sehen so aus: `beispiel.vok`.
- Alles, was das Programm wörtlich anzeigt — eine Meldung, eine Schaltfläche, eine
  Spaltenüberschrift — ist so zitiert, wie es auf dem Bildschirm erscheint.
