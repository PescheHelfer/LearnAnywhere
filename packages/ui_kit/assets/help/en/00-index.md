# Learn Anywhere user guide

Learn Anywhere drills anything you can write down as a set of connected facts —
vocabulary, formulas, dates, chemical symbols, legal paragraphs, anatomy terms. The
program itself knows nothing about any subject. **You** describe what one card looks
like, and Learn Anywhere handles the asking, the grading and the bookkeeping.

This guide ships inside the program, so it is available offline at any time under
**Help ▸ User guide**, or by pressing `F1`. It opens *over* whatever you are doing —
including a running practice session or an unsaved edit — and `Esc` puts you back
exactly where you were.

## Where to start

If you have never used Learn Anywhere, read [Getting started](01-getting-started.md)
and then [Concepts](02-concepts.md). Between them they explain the two ideas the rest
of the program is built on: a **mask** describes the shape of your cards, and a
**deck** holds the cards themselves.

If you are coming from the original *Lern PC plus*, the vocabulary has changed but the
ideas have not: a mask is still the form you fill in, a deck is still your file of
learning units, and the drill still runs until everything is mastered.

## How this guide is written

- Menu paths look like **File ▸ Load deck...**, spelled exactly as the program spells
  them. Switching the interface language changes those labels; this guide is
  translated alongside them, so the German guide names the German labels.
- Keys look like `F3`, `Esc`, `Ctrl`, `Alt+H`.
- File names look like `example.vok`.
- Anything the program shows you verbatim — a message, a button, a column heading — is
  quoted the way it appears on screen.
