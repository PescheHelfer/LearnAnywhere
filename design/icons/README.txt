Learn Anywhere icon set

Windows
-------
Use learn-anywhere.ico as the executable/application icon.
It contains 16, 24, 32, 48, 64, 128 and 256 pixel variants.

Linux
-----
The linux folder contains individual PNG files.
The linux-hicolor folder follows the usual freedesktop icon-theme layout.

A typical system-wide installation target is:
  /usr/share/icons/hicolor/<size>x<size>/apps/learn-anywhere.png

A typical per-user installation target is:
  ~/.local/share/icons/hicolor/<size>x<size>/apps/learn-anywhere.png

After installation, the desktop file can use:
  Icon=learn-anywhere

The 1024-pixel PNG is included as the high-resolution master.
Small sizes received mild sharpening, but they are resized versions rather
than separately redrawn pixel-art icons.
